# 产品价值：把"模型上板、稳、快、可更新"做成可复现、可度量的交付

## 一句话
你的产品价值**不在"发行版"本身**，而在**把 AI 模型在特定硬件上稳定、高性能地跑起来并可持续交付**的能力。

## 对客户的价值

| 维度 | 客户得到什么 | 可证明的方式 |
| --- | --- | --- |
| **省时间** | 从"模型 + 板子"到"可交付服务"，把数天/数周底层集成压缩掉 | 一条命令从零到运行（quickstart） |
| **降风险** | 稳定（长时间不倒）、可复现（换机器一致）、可更新（OTA 不砖） | soak test、KAS 锁版本、A/B 升级 |
| **高性能** | 推理延迟/吞吐达标，资源用到刀刃上 | TensorRT 基准、量化前后对比 |
| **省钱** | 最小镜像 + 更便宜板子 + 更低功耗 | 镜像大小、功耗、BOM 对比 |

## 市场空位（详见 `13-landscape.md`）

- **开发体验**有人做了：`jetson-containers`（~4.9k★）、`jetson-inference`（~9k★）。
- **BSP**有人做了：`meta-tegra`（~580★）、`tegra-demo-distro`。
- **通用边缘 OS / OTA**有人做了：Balena、Torizon、Foundries；`Mender`、`RAUC`。
- **缺的是**：开源、最小、可复现、**面向生产上板**、带**稳定/性能数据**的发行版。

> 开发体验别人做了，**生产交付（更小、更稳、可复现、可更新、有数据）没人做**。

## 不可替代的部分（人）

- 软件从 **BSP 到 UI 全栈**都懂（少见的组合）；
- 有**真实在维护的仓库**（`embedai`）作为活证据；
- 多年系统经验 = 出问题时能**兜底**。

## 不是价值的（是手段）

发行版本体、Yocto/BitBake 管道、支持多少块板子——这些是**实现手段**，不是卖点。

## 必须测出来、对外证明的 5 个数字

> 没有这些数字，价值只是口号。每个都要有"测量方法 + 脚本 + 可复现"。

1. **镜像大小**：vs JetPack / jetson-containers（越小越能省存储/带宽）。
2. **启动时间**：从上电/引导到服务可用（`systemd-analyze`）。
3. **内存占用**：空闲 + 满载（`free`、`ps_mem`）。
4. **功耗**：空闲 + 推理满载（USB 功率计）。
5. **推理性能**：延迟 / FPS / 精度（TensorRT，同一模型的量化前后对比）。

> 可选第 6 个：**稳定性**（soak test 连续运行小时数无崩溃/无降频异常）。

## 如何用这些价值拿流量与好评

- **对比实测**是最强钩子：同一模型在 embedai vs JetPack vs jetson-containers 上的 5 个数字。
- **诚实标注限制**（QEMU 无 GPU、目前只支持 Jetson）→ 反而增加可信度。
- 数据 → 文章 → 视频 → GitHub star / Release 下载 → 客户线索。
